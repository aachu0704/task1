# Hangman Game

## Project Overview
A simple text-based Hangman game developed using Python.

## Features
- Five predefined words
- Random word selection
- One-letter-at-a-time guessing
- Maximum of six incorrect guesses
- Displays correct and incorrect guesses
- Detects win and loss conditions

## Technologies Used
- Python
- Random module
- While loops
- If-else statements
- Strings and lists

## How to Run
1. Download or clone this repository.
2. Install Python 3 if it is not already installed.
3. Open a terminal in the project folder.
4. Run `python3 hangman.py`.

## Concepts Learned
Random selection, loops, conditional statements, strings, lists, and user input.
